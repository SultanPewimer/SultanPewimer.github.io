# Website Portofolio — Muhammad Sultan Fajar Saepudin

Website portofolio pribadi Muhammad Sultan Fajar Saepudin, mahasiswa D4 Teknologi Game di Politeknik Elektronika Negeri Surabaya (PENS). Website ini memperkenalkan profil, keahlian, pengalaman, dan kontribusi pada proyek game dalam bidang Game Design, Game UI Design, serta Graphic Design.

## Isi Website

- **Home:** nama, spesialisasi, pengantar, dan akses ke daftar proyek.
- **About Me:** foto diri, profil, pendidikan, domisili, asal daerah, dan pengalaman PKL di LINES LDII TV.
- **Skills & Tools:** UI Design, Graphic Design, Game Design, bahasa Inggris, serta Figma, CorelDRAW, dan Photoshop.
- **Projects:** empat proyek game dengan thumbnail screenshot, tahun, genre, dan peran.
- **Project Details:** overview, Role & Tools, Contributions, Project Gallery, dan link Play Game.
- **Contact:** alamat email dan link WhatsApp / Telepon.

## Proyek yang Ditampilkan

| Proyek | Tahun | Peran |

| Fragile Delivery | 2025 | Team Lead, Game Designer & UX Designer |

Setiap galeri menggunakan screenshot proyek dengan caption dan urutan yang ditentukan pemilik portofolio. Link Play Game mengarah ke halaman masing-masing game di itch.io.

## Teknologi dan Tampilan

Website menggunakan HTML5, CSS3, dan JavaScript vanilla, tanpa framework, backend, atau database. Tampilan memakai dark mode dengan warna charcoal dan aksen lime, serta layout responsif untuk desktop, tablet, dan mobile.

Navigasi mendukung keyboard, indikator fokus, menu mobile, dan preferensi reduced motion. Detail proyek ditampilkan melalui dialog yang dapat ditutup dengan tombol atau Escape. Foto dan screenshot mempertahankan rasio aslinya.

## Struktur File

```text
index.html    Konten dan struktur halaman
style.css     Tema visual dan layout responsif
script.js     Data proyek dan interaksi website
assets/       Favicon, foto diri, gambar tools, dan screenshot game
README.md     Penjelasan website dan deklarasi penggunaan AI
```

Seluruh aset lokal menggunakan path relatif dengan nama file yang harus ditulis sesuai huruf besar/kecilnya. Website kompatibel dengan GitHub Pages dan tidak memerlukan proses build.

## Menjalankan Website

Buka `index.html` langsung di browser, atau jalankan server lokal dari folder proyek:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Kemudian buka http://127.0.0.1:8080. Hentikan server dengan Ctrl+C. Fitur salin email mengikuti dukungan dan izin clipboard browser.

## Deklarasi Penggunaan AI

Pengembangan website portofolio ini menggunakan bantuan AI melalui ChatGPT/Codex. AI membantu menyusun kode awal HTML, CSS, dan JavaScript, merancang tata letak, menerapkan revisi berdasarkan arahan pemilik, menulis dokumentasi, serta melakukan pemeriksaan teknis.

Informasi profil, pendidikan, pengalaman, daftar keahlian, peran, kontribusi, dan deskripsi proyek mengacu pada informasi yang diberikan pemilik portofolio. Penggunaan AI dalam pengerjaan website tidak digunakan untuk menambahkan pencapaian atau kontribusi yang tidak diberikan.

Foto diri, gambar tools, dan screenshot game disediakan melalui direktori aset proyek. Dalam pengerjaan website ini, file-file tersebut digunakan tanpa membuat ulang atau mengubah isi visualnya.

Cakupan deklarasi ini adalah pengembangan website portofolio. Deklarasi ini tidak menetapkan penggunaan AI dalam proses pengembangan game maupun pembuatan aset proyek yang ditampilkan.
